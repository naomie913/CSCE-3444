# CSCE 3444 - Software Enigineering-UNT Building Navigation

## Project Description
UNT Building Navigation is an application designed to help students, faculty, and staff navigate inside buildings on the University of North Texas campus.

The application will allow users to search for buildings, rooms, and destinations and receive clear navigation directions.
